Settings

Voice input

Hold the voice shortcut while you speak and release it to send. A quick tap starts recording until you press the shortcut again. Recordings go only to this server, which must run on this PC.

Speech output

Replies are read aloud with a Windows voice, named as in Windows speech settings (for example "Microsoft Zira Desktop"). If you run an OpenAI-compatible speech server on this PC, enter its URL and model to use it instead; the Windows voice then takes over whenever that server does not answer. Rate and pitch apply to Windows voices.
